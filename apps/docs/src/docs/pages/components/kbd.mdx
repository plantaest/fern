## API Reference

<div class="fern-docs-api-table" role="region" aria-labelledby="api-reference" tabindex="0">

| Prop       | Type                | Default     | Description                                                                                        |
| ---------- | ------------------- | ----------- | -------------------------------------------------------------------------------------------------- |
| `children` | Text or JSX         | —           | The visible key or shortcut.                                                                       |
| `size`     | `"sm" \| "default"` | `"default"` | `default` uses 14px text and a 22px minimum height. `sm` uses 12px text and a 20px minimum height. |
| `...props` | Native `kbd` props  | —           | Forwards attributes, events, and the ref to the `kbd` element.                                     |

</div>

## Accessibility

- `Kbd` displays the key. The application implements any shortcut it describes.
- Use readable key names, such as `Enter`, when a symbol alone could be unclear.
- Hide a redundant hint with `aria-hidden="true"` when the control already communicates the same interaction, as in the link example.
