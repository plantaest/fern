## Accessibility

- `Kbd` displays the key. The application implements any shortcut it describes.
- Use readable key names, such as `Enter`, when a symbol alone could be unclear.
- Hide a redundant hint with `aria-hidden="true"` when the control already communicates the same interaction, as in the link example.
