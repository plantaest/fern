## API Reference

<div class="fern-docs-api-table" role="region" aria-labelledby="api-reference" tabindex="0">

| Prop       | Type               | Default | Description                                                                         |
| ---------- | ------------------ | ------- | ----------------------------------------------------------------------------------- |
| `ratio`    | `number`           | `1`     | Width divided by height. Use a finite positive number, such as `4 / 3` or `16 / 9`. |
| `children` | `JSX.Element`      | —       | Content inside the frame. Size and position it with CSS.                            |
| `...props` | Native `div` props | —       | Forwards attributes, events, and the ref to the frame.                              |

</div>
