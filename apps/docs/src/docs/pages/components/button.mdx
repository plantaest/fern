<details class="mt-4 [&_p]:pt-3">
  <summary><code>buttonVariants()</code> — classes for a native link</summary>
  <div class="text-[13px] leading-5">

A CVA function accepting `variant`, `size`, and either `class` or `className`. Additional classes can be strings, arrays, or conditional objects. Omit a variant to use its default; pass `null` to skip it. Returns a class string; it does not add behavior.

<Section title="Accessibility">

- Tab moves focus to enabled buttons. Enter or Space activates them.
- Focus has a visible Codex outline in both themes.
- Give icon-only buttons an `aria-label`. Decorative icons stay hidden from assistive technology.
- Use words as well as color to describe destructive actions and busy states.
- The `link` variant changes appearance only. Use a native anchor for navigation.

</Section>
