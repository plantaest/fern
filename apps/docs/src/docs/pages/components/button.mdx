## API Reference

Use `variant` for style and `action` for meaning.

<div class="max-w-full overflow-x-auto border-y border-line-subtle fern-docs-api-table">

| Prop       | Type                                                            | Default     |
| ---------- | --------------------------------------------------------------- | ----------- |
| `variant`  | `"solid" \| "soft" \| "surface" \| "outline" \| "ghost"`        | `"solid"`   |
| `action`   | `"neutral" \| "progressive" \| "destructive"`                   | `"neutral"` |
| `size`     | `"sm" \| "default" \| "lg" \| "icon-sm" \| "icon" \| "icon-lg"` | `"default"` |
| `disabled` | `boolean`                                                       | `false`     |
| `type`     | `"button" \| "submit" \| "reset"`                               | `"button"`  |
| `class`    | `string`                                                        | —           |
| `children` | Text, icons, or other JSX                                       | —           |
| `as`       | Element or component                                            | `"button"`  |

</div>

Supports props, refs, and events for the rendered element or component. See the [Kobalte Button API](https://kobalte.dev/docs/core/components/button/).

## Accessibility

- Tab moves focus to enabled controls. Buttons activate with Enter or Space; links activate with Enter.
- Focus has a visible outline in both themes.
- Give icon-only buttons an `aria-label`. Decorative icons stay hidden from assistive technology.
- Use words as well as color to describe destructive actions and busy states.
