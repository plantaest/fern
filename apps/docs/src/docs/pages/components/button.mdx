## API Reference

<div class="fern-docs-api-table" role="region" aria-labelledby="api-reference" tabindex="0">

| Prop       | Type                                                                                               | Default     | Description                                                                                                                |
| ---------- | -------------------------------------------------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------- |
| `variant`  | `"solid"`<br />`\| "soft"`<br />`\| "surface"`<br />`\| "outline"`<br />`\| "ghost"`               | `"solid"`   | Selects the visual style.                                                                                                  |
| `action`   | `"neutral"`<br />`\| "progressive"`<br />`\| "destructive"`                                        | `"neutral"` | Conveys the meaning of the action.                                                                                         |
| `size`     | `"sm"`<br />`\| "default"`<br />`\| "lg"`<br />`\| "icon-sm"`<br />`\| "icon"`<br />`\| "icon-lg"` | `"default"` | Sets the size. Use an icon size for buttons with no visible text.                                                          |
| `disabled` | `boolean`                                                                                          | `false`     | Prevents activation.                                                                                                       |
| `type`     | `"button"`<br />`\| "submit"`<br />`\| "reset"`                                                    | `"button"`  | Sets the native button behavior in a form.                                                                                 |
| `class`    | `string`                                                                                           | —           | Adds CSS classes to the rendered element.                                                                                  |
| `children` | Text or JSX                                                                                        | —           | Content of the button, including its label and any icons.                                                                  |
| `as`       | Element or component                                                                               | `"button"`  | Renders another element or component. Use an anchor for navigation.                                                        |

## Accessibility

- Tab moves focus to enabled controls. Buttons activate with Enter or Space; links activate with Enter.
- Focus has a visible outline in both themes.
- Give icon-only buttons an `aria-label`. Decorative icons stay hidden from assistive technology.
- Use words as well as color to describe destructive actions and busy states.
