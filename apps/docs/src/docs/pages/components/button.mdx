| Prop       | Type                                                            | Default     |
| ---------- | --------------------------------------------------------------- | ----------- |
| `variant`  | `"solid" \| "soft" \| "surface" \| "outline" \| "ghost"`        | `"solid"`   |
| `action`   | `"neutral" \| "progressive" \| "destructive"`                   | `"neutral"` |
| `size`     | `"sm" \| "default" \| "lg" \| "icon-sm" \| "icon" \| "icon-lg"` | `"default"` |
| `disabled` | `boolean`                                                       | `false`     |
| `type`     | `"button" \| "submit" \| "reset"`                               | `"button"`  |
| `class`    | `string`                                                        | —           |
| `children` | Text, icons, or other JSX                                       | —           |

<Section title="Accessibility">

- Tab moves focus to enabled buttons. Enter or Space activates them.
- Focus has a visible outline in both themes.
- Give icon-only buttons an `aria-label`. Decorative icons stay hidden from assistive technology.
- Use words as well as color to describe destructive actions and busy states.

</Section>
