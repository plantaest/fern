### Media

#### Cover image

Place `AspectRatio` inside `CardMedia` to size a cover image. In the default `block-start` position, the image sits above the content and follows the card's padding.

## API Reference

### Card

<div class="fern-docs-api-table" role="region" aria-labelledby="card" tabindex="0">

| Prop       | Type                           | Default | Description                                          |
| ---------- | ------------------------------ | ------- | ---------------------------------------------------- |
| `as`       | Element tag or Solid component | `"div"` | Changes the root element.                            |
| `children` | `JSX.Element`                  | —       | The content of the card. Compose sections as needed. |
| `...props` | Props of the rendered element  | —       | Forwards attributes, events, and the ref.            |

</div>

### CardMedia

Place one optional `CardMedia` as the first child of `Card`. It renders a `div` and can contain an image or a decorative icon.

<div class="fern-docs-api-table" role="region" aria-labelledby="cardmedia" tabindex="0">

| Prop       | Type                                                                   | Default         | Description                                                   |
| ---------- | ---------------------------------------------------------------------- | --------------- | ------------------------------------------------------------- |
| `position` | <code>"block-start"<br />\| "inline-start"<br />\| "inline-end"</code> | `"block-start"` | Places media above the content or beside it in a 48px square. |
| `...props` | Native `div` props                                                     | —               | Forwards attributes, events, and the ref.                     |

</div>

### CardHeader

Groups the title and description. Accepts native `div` props.

### CardTitle

Renders a `div` by default. Use `as` to render a heading when the card introduces a section.

### CardDescription

Displays supporting text in a `div`. Accepts native `div` props.

### CardContent

Holds the main content of the card. Accepts native `div` props.

### CardFooter

Renders a flex row with vertically centered items. Use `class` to adjust spacing, wrapping, or alignment. Accepts native `div` props.

## Accessibility

- Use `as="article"` when the card represents an item that makes sense on its own, such as an article preview or a review task.
- A linked card can use `aria-labelledby` to take its accessible name from the title.
- Give informative images descriptive `alt` text. Use `alt=""` when the image is decorative or repeats nearby content.
- A linked card is one Tab stop and opens with Enter. Keep links, buttons, and other controls outside a linked card. For a card with separate actions, Tab moves through the controls in document order.
