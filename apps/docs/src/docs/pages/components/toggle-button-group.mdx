## API Reference

### ToggleButtonGroup

<div class="fern-docs-api-table" role="region" aria-labelledby="api-reference" tabindex="0">

| Prop           | Type                                | Default        | Description                                                                        |
| -------------- | ----------------------------------- | -------------- | ---------------------------------------------------------------------------------- |
| `multiple`     | `boolean`                           | `false`        | Allows multiple items to be pressed at once.                                       |
| `value`        | `string \| null`<br />`string[]`    | —              | Controls the selection. Pass `null` or an empty array to clear it.                 |
| `defaultValue` | `string \| null`<br />`string[]`    | —              | Sets the initial selection when the group manages its own state.                   |
| `onChange`     | `(value) => void`                   | —              | Receives a string or `null` in single selection, or an array with `multiple`.      |
| `orientation`  | `"horizontal"`<br />`\| "vertical"` | `"horizontal"` | Arranges the buttons in a row or column and sets the direction of arrow keys.      |
| `variant`      | `"surface"`<br />`\| "ghost"`       | `"surface"`    | Joins `surface` buttons by their borders or spaces out borderless `ghost` buttons. |
| `size`         | `ButtonSize`                        | `"default"`    | Sets the same [Button size](/components/button#sizes) for every item.              |
| `disabled`     | `boolean`                           | `false`        | Disables every item in the group.                                                  |
| `children`     | `JSX.Element`                       | —              | The toggle items in the group.                                                     |
| `...props`     | Native `div` props                  | —              | Forwards applicable attributes, events, and the ref to the group element.          |

</div>

<div class="fern-docs-api-table" role="region" aria-labelledby="togglebuttongroupitem" tabindex="0">

</div>

## Accessibility

- Name the group with `aria-label` or `aria-labelledby`. Give each icon-only button its own `aria-label` and keep its name stable when pressed.
- Tab and Shift+Tab move through enabled buttons. Use Left and Right in a horizontal group, or Up and Down in a vertical group, to move focus between enabled buttons. Arrow keys stop at the ends. In RTL, horizontal arrows follow the visual order.
- Press Enter or Space to change the selection.
