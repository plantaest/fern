## Examples

### Variants

Use `Button` components as direct children of the group and set `disabled` on each button that should be unavailable. Use the checkbox to compare enabled and disabled states across the five variants.

<Example demo={buttonGroupVariantsExample} />

### Orientation

Buttons sit in a single row by default. Set `orientation="vertical"` to stack them, for example when a row would be too wide for its container.

<Example demo={buttonGroupOrientationExample} />

### Icon-only

Use an icon-only group for recognizable actions such as zooming. Give each button its own `aria-label`.

<Example demo={buttonGroupIconOnlyExample} />

## API Reference

| Prop          | Type                                | Default        | Description                                                    |
| ------------- | ----------------------------------- | -------------- | -------------------------------------------------------------- |
| `orientation` | `"horizontal"`<br />`\| "vertical"` | `"horizontal"` | Arranges the buttons in a row or column.                       |
| `children`    | `JSX.Element`                       | —              | The buttons to join.                                           |

## Accessibility

- Name the group by its purpose. Use `aria-labelledby` when there is a visible label or `aria-label` when there is none.
- Give each button its own accessible name. Use Tab and Shift+Tab to move between enabled controls.
