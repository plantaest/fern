## API Reference

<div class="fern-docs-api-table" role="region" aria-labelledby="api-reference" tabindex="0">

| Prop          | Type                                | Default        | Description                                                   |
| ------------- | ----------------------------------- | -------------- | ------------------------------------------------------------- |
| `orientation` | `"horizontal"`<br />`\| "vertical"` | `"horizontal"` | Sets the direction of the line.                               |
| `decorative`  | `boolean`                           | `false`        | Hides the line from assistive technology.                     |
| `...props`    | Native `hr` props                   | —              | Forwards attributes, events, and the ref to the `hr` element. |

## Accessibility

- Use `decorative` for a visual line between items that already have a clear structure, such as links in one navigation group.
- A semantic vertical separator sets `aria-orientation="vertical"`. Separators are static and stay out of the tab order.
