## API Reference

<div class="fern-docs-api-table" role="region" aria-labelledby="api-reference" tabindex="0">

| Prop       | Type               | Default | Description                                                   |
| ---------- | ------------------ | ------- | ------------------------------------------------------------- |
| `animate`  | `boolean`          | `true`  | Pulses continuously. Set to `false` for a static placeholder. |
| `...props` | Native `div` props | —       | Use `class` or `style` to size and shape the placeholder.     |

</div>

## Accessibility

- Skeletons are hidden from assistive technology. Set `aria-busy` on the region being updated while its content loads.
- If you need to announce loading, use one `role="status"` message outside the busy region for the whole group.
- Skeletons are static when reduced motion is enabled.
