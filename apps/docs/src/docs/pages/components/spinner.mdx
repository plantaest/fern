## API Reference

| ------------ | -------------------------------------------------------- | ----------- | ------------------------------------------------------------- |

## Accessibility

- The spinner has `role="status"` by default. Set `aria-hidden="true"` when nearby text already describes the loading state.
- Set `aria-busy` on the region being updated. To announce changes, update the text of an existing `role="status"` region outside the busy region.
- The spinner stops rotating when reduced motion is enabled.
