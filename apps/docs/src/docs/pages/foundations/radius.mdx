## Default

Use `rounded-base` or `--fern-radius-base`. The default is 0.25rem.

<RadiusDefault />

## Pill

Use `rounded-pill` or `--fern-radius-pill` for fully rounded ends, as in [Badge](/components/badge).

## Circle

Use `rounded-circle` or `--fern-radius-circle` to apply a 50% radius. On a square, this produces a circle, as in [Avatar](/components/avatar).
