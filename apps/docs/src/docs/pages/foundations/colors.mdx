## Usage

Wrap content in `.fern` and select `data-theme="light"` or `data-theme="dark"`. Use semantic tokens in CSS:

```css
.panel {
  color: var(--fern-color-base);
  background: var(--fern-background-color-base);
  border: 1px solid var(--fern-border-color-subtle);
}
```

The optional Tailwind adapter groups colors into `content-*`, `surface-*`, and `line-*`:

```tsx
<div class="bg-surface-base text-content-base">Panel content</div>
```

Use `text-content-progressive` for text, `bg-surface-progressive` for a background, and `border-line-progressive` for a border. These roles can have different values in the same theme.
