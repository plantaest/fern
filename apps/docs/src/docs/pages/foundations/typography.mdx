## Scales

Font size, line height, and weight use independent scales. Use the CSS variables inside `.fern` or the matching utilities from the optional Tailwind adapter.

Pixel equivalents assume a 16px root font size. Unitless line height scales with the element's font size.

Combine one token from each scale to style an interface label:

```css
.label {
  font-size: var(--fern-font-size-small);
  line-height: var(--fern-line-height-small);
  font-weight: var(--fern-font-weight-medium);
}
```

## Text styles

`text-body` combines 16px text with 1.625 leading. `text-small` and `text-extra-small` combine 14px and 12px text with 20px leading. `text-heading-1` through `text-heading-6` combine heading sizes and leading. Family and weight remain separate.

## Prose

Use `fern-prose` inside `.fern` for document HTML or rendered Markdown. It styles headings, paragraphs, links, lists, quotes, code, tables, and figures. Layout controls the width.

```html
<article class="fern-prose">
  <!-- Document content -->
</article>
```

Set `--fern-prose-flow` on the container to adjust block spacing. It defaults to 16px. Add `fern-not-prose` to embedded UI to exclude its elements from prose styles.

### Small tools, shared knowledge

Good interfaces help people understand what they can do and what happens next. Fern makes room for the content and keeps the controls familiar.

<h3 lang="vi" id="tri-thức-mở-cho-mọi-người">
  {'Tri thức mở cho mọi người'}
</h3>

<p lang="vi">
  {'Tri thức mở bắt đầu từ những đóng góp nhỏ. Mỗi thay đổi đều có thể làm Wikipedia tốt hơn.'}
</p>

#### Clear next steps

Use headings to organize a page. Keep labels short, and use plain language when something needs an explanation.

- **Make the next step clear.** Use familiar words for actions.
- Let content use _natural HTML_, including lists and links.
- Read the [Wikimedia typography guide](https://doc.wikimedia.org/codex/latest/style-guide/typography.html) for context.

> Small tools can make shared knowledge easier to build.

| Context     | Typography                           |
| ----------- | ------------------------------------ |
| Documents   | 16px body with 26px line-height      |
| Controls    | 14px text with compact spacing       |
| Code blocks | 14px monospace with 20px line-height |
