# Changelog

## Unreleased

- A reusable Solid package with AspectRatio, Badge, Button, ButtonGroup, Collapsible, Message, Separator, Skeleton, Spinner, ToggleButton, ToggleButtonGroup, decorative Codex Icons, public types, and compiled CSS.
- Light and Dark themes preserving Codex 2.8.0 colors and semantic roles, scoped to `.fern`. Independent typography tokens, shared spacing, radius, and transition tokens, document styles with visited link states and adjustable block spacing through `.fern-prose`, color data, and an optional Tailwind 4 adapter.
- The Tailwind adapter provides utilities for the Codex palette and semantic color roles.
- Badge with five variants, six statuses, three sizes, icon composition, and native link rendering.
- Button with separate visual variants and semantic actions, variant-specific disabled styles, three sizes with matching icon-only forms, and polymorphic rendering. Navigation uses native anchors.
- ButtonGroup with joined buttons in horizontal or vertical layouts.
- Collapsible disclosures that preserve content and form values when closed.
- Message with four feedback statuses, block and inline layouts, optional titles and custom icons, and an app-controlled close button.
- Separator with horizontal and vertical orientations and a decorative option.
- Skeleton placeholders with a pulse that respects reduced motion.
- Spinner loading indicators with four sizes and reduced-motion support.
- ToggleButton with surface and ghost variants and controlled or uncontrolled pressed state.
- ToggleButtonGroup with single or multiple selection, surface and ghost variants, and arrow-key navigation.
- Fern Docs with MDX pages, syntax-highlighted code blocks, interactive playgrounds, standalone demos for previews and displayed source, and pathname routing.
- Formatting, linting, component and Docs tests, clean tarball verification, and manually triggered CI.

The initial alpha is unpublished. Kobalte remains a prerelease dependency; publication is pending compatibility and package scope confirmation.
