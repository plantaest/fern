# Changelog

## Unreleased

- A reusable Solid package with Button, decorative Codex Icons, public types, and compiled CSS.
- Light and Dark themes preserving Codex 2.7.0 colors and semantic roles, scoped to `.fern`. Independent typography tokens, shared spacing, radius, and transition tokens, document styles with adjustable block spacing through `.fern-prose`, color data, and an optional Tailwind 4 adapter.
- Button with separate visual variants and semantic actions, three sizes with matching icon-only forms, polymorphic rendering, and reduced-motion support. Navigation uses native anchors.
- Fern Docs with MDX pages, interactive playgrounds, standalone demos for previews and displayed source, and pathname routing.
- Formatting, linting, component and Docs tests, clean tarball verification, a Shadow DOM host fixture, and manually triggered CI.

The initial alpha is unpublished. Solid and Kobalte remain prerelease dependencies; publication is pending compatibility and package scope confirmation.
